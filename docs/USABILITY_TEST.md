# Usability test: C7 "Same again?"

Template for spec section 6.3, criterion 6: "Three people who have never seen it complete it on a phone with no instructions. Record the times for the write-up." **Do not fill in personal details**: use a participant code (P1, P2, P3), never a name or phone number.

## Before the session

- [ ] Run `pnpm seed`, then place and pay one order as the participant would have (so a "usual" exists).
- [ ] Copy the private link shown on the confirmation page (C6).
- [ ] Phone: a mid-range Android or iPhone, screen about 360 px wide. Note the model and browser below.
- [ ] Connection: normal mobile data, or throttled Slow 4G if testing on a laptop.
- [ ] Start a timer (phone stopwatch) and a tally for taps.
- [ ] Say only the task wording below. Do not explain the app, point, or help unless the participant is stuck for 60 seconds.

## Task wording (read exactly)

> "You bought a drink from GoodCane last week and liked it. Here is your link from last time. Order the same again for the next drop and get to the payment screen."

Hand over the phone with the link open in a message or note. Start the timer when they first touch the link.

**Done** = the payment screen (C5, "Demo payment, no real money") is showing. Stop the timer there. Do not ask them to pay.
